# solar-inverter

Модуль на ESP32, который показывает состояние гибридного инвертора
**SD-HYM-4862HWP** и батареи **14S NMC под DALY Smart BMS** веб-страницей
в домашней локальной сети.

Батарея читается по Bluetooth LE — штатный донгл DALY отдаёт тот же нативный
протокол, что и провод. Инвертор подключится по RS485; пока его карточка живёт
на демонстрационных данных.

Штатное приложение инвертора работает через китайское облако, которое из России
не открывается. Это устройство — его локальная замена: ничего не уезжает наружу
и ничего не ломается от блокировок.

## Что уже есть

* Чтение DALY BMS по BLE: заряд, напряжение, ток, ячейки, температуры, защита.
* Дашборд со схемой потоков мощности, режимом инвертора и журналом событий.
* Настройка сети тремя путями: терминал по USB, своя точка доступа,
  Android-приложение по Bluetooth.
* Ярлык на главный экран: страница открывается как приложение, без адресной строки.

## Сборка

```bash
cd firmware
pio run                                       # сборка
pio run -t upload --upload-port /dev/ttyUSB0  # заливка
pio device monitor -b 115200                  # терминал
```

Страница собирается из `firmware/web/index.html`: скрипт `scripts/gen_web.py`
сжимает её в gzip и кладёт в прошивку перед компиляцией.

## Состояние

Работает и проверено на живом железе. Не проверено на живой батарее — смещения
полей протокола DALY и расшифровка битов аварий; батарея пока физически
недоступна. Данные инвертора демонстрационные до появления связи по RS485.
