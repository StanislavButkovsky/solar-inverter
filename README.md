# solar-inverter

Модуль на ESP32, который показывает состояние гибридного инвертора
**SD-HYM-4862HWP** и батареи **14S NMC под DALY Smart BMS** веб-страницей
в домашней локальной сети.

Батарея читается по Bluetooth LE — штатный донгл DALY отдаёт тот же нативный
протокол, что и провод. Инвертор — по Bluetooth через донгл Eybond: внутри
обычный Modbus RTU.

**Устройств два, кодовая база одна.** Второе — под инвертор
**Hiden Control HS35-5648PRO** (он же MUST PV18): тот же Modbus, но по USB
и с другой картой регистров. Различаются профиль и транспорт, весь показ общий.

Штатное приложение инвертора работает через китайское облако, которое из России
не открывается. Это устройство — его локальная замена: ничего не уезжает наружу
и ничего не ломается от блокировок.

## Что уже есть

* Чтение DALY BMS по BLE: заряд, напряжение, ток, ячейки, температуры, защита.
* Дашборд со схемой потоков мощности, режимом инвертора и журналом событий.
* Настройка сети двумя путями: своя точка доступа с формой в браузере
  и терминал по USB.
* Ярлык на главный экран: страница открывается как приложение, без адресной строки.

## Сборка

```bash
cd firmware
pio run -e esp32dev                                      # первое устройство
pio run -e esp32dev -t upload --upload-port /dev/ttyUSB0
pio run -e esp32s3-hs35                                  # второе, под Hiden HS35
pio device monitor -b 115200                             # терминал
```

Страница собирается из `firmware/web/index.html`: скрипт `scripts/gen_web.py`
сжимает её в gzip и кладёт в прошивку перед компиляцией.

## Состояние

Первое устройство работает и проверено на живом железе. Не проверено на живой
батарее — смещения полей протокола DALY и расшифровка битов аварий; батарея
пока физически недоступна. Данные инвертора демонстрационные, пока не привязан
донгл.

Второе устройство собирается, профиль регистров вписан. Не написан драйвер
USB-хоста CH340 — он пишется на приехавшем железе.
