# Настройка Solar — мини-приложение для Android

Один экран: найти модуль по Bluetooth, показать доступные сети Wi-Fi, отдать
модулю имя сети и пароль, увидеть выданный IP-адрес.

Приложение нужно ровно один раз — при первой настройке. Дальше модуль живёт
в сети, и всё происходит на его веб-странице.

## Сборка

Проект без gradle-wrapper (бинарный `gradle-wrapper.jar` в репозитории не хранится).
Любой из двух путей:

```bash
# 1. Android Studio: File → Open → эта папка, wrapper создастся сам
# 2. Из терминала, если Gradle стоит в системе:
gradle wrapper && ./gradlew assembleDebug
```

APK окажется в `app/build/outputs/apk/debug/`.

Требуется JDK 17, Android SDK 34. `minSdk` 24 — Android 7 и новее.

## Разрешения

На Android 12 и новее — `BLUETOOTH_SCAN` (с `neverForLocation`) и `BLUETOOTH_CONNECT`.
На Android 11 и старше система требовала для BLE-поиска доступ к геопозиции, поэтому
там запрашивается `ACCESS_FINE_LOCATION`. Приложение спрашивает разрешения само,
при первом нажатии «Найти устройство».

## Как пользоваться

1. Подать питание на модуль. Он рекламируется как `Solar-XXXX`.
2. «Найти устройство» → выбрать из списка.
3. «Показать сети Wi-Fi» — список приходит от модуля, он сканирует эфир сам,
   своим приёмником. Это важно: телефон и модуль стоят в разных местах и видят
   разные сети, а подключаться будет модуль.
4. Нажать на нужную сеть — имя подставится в поле. Ввести пароль.
5. «Сохранить и перезагрузить». Через несколько секунд в строке состояния появится
   адрес вида `http://192.168.1.42` — его и открывать на планшете.

Только 2,4 ГГц: у ESP32 нет приёмника на 5 ГГц.

## Протокол

Совпадает с `firmware/src/prov.cpp`:

```
сервис  9a1f0001-7f3a-4b0e-9f2b-1c7a5d3e0001
0002 W  имя сети, UTF-8
0003 W  пароль, UTF-8
0004 W  команда: 1 — искать сети, 2 — сохранить и перезагрузиться, 3 — сброс
0005 RN статус строками
```

Строки статуса: `STATE|<текст>|<ip>` и `NET|<rssi>|<открытая 0/1>|<имя сети>`,
конец списка — `NET|END`.

BLE выполняет одну операцию за раз, поэтому записи идут через очередь: следующая
уходит из `onCharacteristicWrite`. Без этого запись пароля затирает запись имени сети.

## Если модуль не находится

Поиск идёт в два захода: сначала по UUID сервиса, потом, если пусто, без фильтра
с отбором по имени `Solar-`. Причина — 128-битный UUID вместе с именем не всегда
помещается в 31 байт рекламного пакета и уезжает в scan response, который часть
прошивок телефонов по фильтру не отдаёт.

Если не помогло и это — настройка никуда не делась: модуль поднимает точку доступа
`solar-setup` (пароль `12345678`), и та же форма открывается на `http://192.168.4.1`.
